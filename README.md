# Cursojava_pre-entrega
# Sistema de Productos y Pedidos

Proyecto realizado en Java para la pre-entrega del curso Back-End.

## Funcionalidades

- Agregar productos
- Listar productos
- Buscar productos por ID
- Actualizar productos
- Eliminar productos
- Crear pedidos
- Validación de stock
- Cálculo de total de pedidos
- Manejo de excepciones

## Estructura del proyecto

- Producto.java
- ProductoService.java
- Pedido.java
- PedidoService.java
- LineaPedido.java
- ProductoNoEncontrado.java
- SistemaProductoMain.java

## Cómo ejecutar

1. Abrir el proyecto en Visual Studio Code
2. Ejecutar la clase principal:
   
   SistemaProductoMain.java

3. Utilizar el menú interactivo desde consola
